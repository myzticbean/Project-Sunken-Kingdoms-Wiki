# Development Status

*As of October 2026.* The game is built one phase at a time, and a phase only counts as done once
it has been checked in game. This page says which parts of the wiki you can play today and which are
still design.

## Built and verified in game

| Phase | What it added |
|---|---|
| 0 | Waygates and the gatehouse: multi-hold delves, barred arches, the drop between holds |
| 1 | The Mouth and its rings, the hearth, the world border, the seal on the Mouth |
| 2, 2b | The knock, the fall, the way home; the ring as a grated well whose cap falls in |
| 3 | The Breath (+10 hearts, no regen, the dead heal) and the seal (no place/break, blank maps, no escape teleports) |
| 4 | Hoards, kingdom veins, tagged loot, stars, remains |
| 5 | Bellmouth's economy: factors, Crowns, Crown Bars, the kit, factor arrivals, the wall |
| 6 | The Waking, the dead rising from the floor, leashes and sleep, marks, wights, robbing |
| 7 | Gate objectives: Slay the Gatekeepers, Hold the Gate |
| 8 | Breaking a gate homeward: the Holdout, the peal, the Oathbound |
